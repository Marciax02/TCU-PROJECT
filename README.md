# Pura Ruta

## Autora

**María Ramírez**

## Acerca del proyecto

Este sitio web fue desarrollado como un proyecto de trabajo para el **Trabajo Comunal Universitario (TCU)**. Su propósito es aplicar de manera práctica los conocimientos básicos adquiridos sobre HTML, CSS y JavaScript.

**Pura Ruta** es una página de turismo local inspirada en Costa Rica. Presenta diferentes destinos y experiencias mediante un diseño adaptable para celulares, tabletas y computadoras.

## Funciones principales

- Carrusel automático de destinos.
- Diseño responsive mediante Flexbox, Grid y media queries.
- Menú de navegación para dispositivos móviles.
- Modo oscuro guardado en el navegador.
- Lista de experiencias favoritas mediante almacenamiento local.
- Hora de Costa Rica actualizada automáticamente.
- Formulario con validación en JavaScript.
- Imágenes locales optimizadas para mejorar la velocidad de carga.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
